Démarrer l'application web

Mode 1 · UN CLIC (dev Win)

Lance 4 services d'un coup (brain, gateway, engine, UI).

PS cd antaerus\scripts
powershell -ExecutionPolicy Bypass -File .\dev-all.ps1
Web :5173 Gateway :8080 Brain :8000 Engine :7000/7001
Ouvrir http://localhost:5173 ↗

Mode 1b · Arrêter tout

PS cd antaerus\scripts
powershell -ExecutionPolicy Bypass -File .\stop-all.ps1

PIDs sauvegardés dans %TEMP%\antaerus-dev-all-processes.json.

Mode 2 · Build + Bundle prod

PS cd antaerus\scripts\release
powershell -ExecutionPolicy Bypass -File .\build_bundle.ps1

$ bash ./build_bundle.sh   # Linux

Dossier aNtaerus/bundle/ : zip + MANIFEST + SHA256.

Mode 3 · Docker run direct UI statique (démo sans backend)

PS cd antaerus\interfaces\web ; npm run build
docker run -d --name antaerus-web --rm -p 80:80 -v "C:\chemin\dist:/usr/share/nginx/html:ro" nginx:1.27-alpine

Les 10 écrans de l'interface web

7.1 Setup · Configuration initiale

URL : http://localhost:5173/setup ↗

Wizard 5 étapes : (1) Licence MIT, (2) Chemins sauvegarde mémoire, (3) Fournisseur + Test connexion LLM, (4) Voix, (5) Terminer.

7.2 Chat texte · Conversations LLM

URL : http://localhost:5173/chat ↗

Streaming token par token SSE, historique multi-session SQLite. Ctrl+Enter pour envoyer. Menu sur chaque message (Copier / Réessayer / Supprimer).

7.3 Voix temps réel (M3) · Micro → Transcription

Depuis Chat, icône micro. VoiceButton (record start/stop), VoiceVisualizer (waveform SVG live), VoiceTranscript mot par mot. VAD auto (silence > 1.5s = stop).

Note : micro interdit par Chrome sur IP non-localhost. Utilisez HTTPS ou drapeau #unsafely-treat-insecure-origin-as-secure.

7.4 Missions (M2/M4) · Objectifs + DAG tâches

URL : http://localhost:5173/missions ↗

3 onglets : Toutes / Créer / Détail avec TaskGraph SVG DAG (0-dépendance, dépendances flèches colorées par état).

7.5 Memory Explorer (M1/M6) · Graphe mémoire

URL : http://localhost:5173/memory-explorer ↗

SVG circular layout + Bézier curves (0-dépendance). Cliquez un nœud → FactCard side panel. Recherche plein texte, Export JSON.

7.6 Command Center (M5) · Autonomie + Initiatives

URL : http://localhost:5173/command-center ↗

AutonomySlider niveaux 0 (manuel) → 5 (total). Cards InitiativeCard (catégorie · risque · budget) avec boutons Approuver / Rejeter (motif min 8 chars).

# Declencher curateur manuellement (sinon 2h UTC):
PS Invoke-RestMethod -Method POST http://localhost:8080/api/v1/proactive/curator/run-now -Headers @{Authorization="Bearer dev-jwt-gateway"}

7.7 Analytics (M6) · KPIs + graphiques SVG

URL : http://localhost:5173/analytics ↗

MetricsChart custom SVG (barres + lignes). 4 blocs : missions / mémoire / voice minutes / fuel sandbox M7. Export CSV.

7.8 System Health (M6) · Services temps réel

URL : http://localhost:5173/system-health ↗

4 cards ServiceStatusCard (Web / Gateway / Brain / Engine) voyant vert/orange/rouge. Refresh auto 5s. Logs 100 lignes admin.

7.9 Config · Modifier après setup

URL : http://localhost:5173/config ↗

Formulaire complet ConfigForm. Sauvegarder = push immédiat gateway → brain (persisté dans .env runtime).

7.10 Skill Lab (M7 ⭐ NOUVEAU) · Marketplace / Editor / Tester

URL : http://localhost:5173/skill-lab ↗

3 onglets en haut. Bandeau approbations pending visible immédiat si skills en attente. Voir section 8 pour pas à pas détaillé.

08

Skill Lab M7 — pas à pas (compétences custom)

1
Marketplace — packages curated

3 skills inclus par défaut : echo-json (python), sha256 (stdlib), wasm-add-forty-two (WASM Rust +42). Cliquer carte → panel → Installer / Aperçu code.

2
Skill Editor — 0 dépendance

Editeur textarea custom : line-numbers synchronisés scroll, Tab = 2 espaces, Ctrl+S sauvegarde draft localStorage. Bouton « Générer depuis usage » appelle /skills/generate (ou fallback local JS).

3
Créer skill hello-somme (exemple)
# Nom: hello-somme · Runtime: python
# Usage: "Prend a,b JSON → renvoie somme"
import json, sys
def main() -> dict:
    p = json.loads(sys.argv[1] if len(sys.argv)>1 else "{}")
    return {"result": int(p.get("a",0)) + int(p.get("b",0)), "skill": "hello-somme"}
if __name__ == "__main__":
    print(json.dumps(main(), ensure_ascii=False))
4
Bandeau approbations (Approuver / Rejeter)

En attente → Approuver devient installed (disponible Tester). Rejeter → motif min 8 caractères (double garde : frontend + backend 400 si < 8).

5
Skill Tester — Run sandbox isolé

Choisir skill + Arguments JSON (ex: {"a":18,"b":24}) + Mode sandbox (Auto / Forcer local / Docker). Résultat badges : exitCode, durationMs, fuel, sandboxKind.

# Exemple reponse badge OK + JSON:
exitCode=0  durationMs=145  fuel=382  sandboxKind=python-local-fallback
# Corps:
{"result": 42, "status": "ok", "skill": "hello-somme"}

FAQ dépannage fréquent

Cause : Gateway Go arrêté. Relancez scripts\dev-all.ps1 ou autorisez go.exe dans Pare-feu Windows → Règles entrantes.

Vérifiez antaerus/.env clé API SANS espaces/guillemets. Test brain direct: Invoke-RestMethod http://localhost:8000/health → status ok. Si Ollama: ollama list.

Déjà CORRIGÉ code (sys.executable PREMIER ordre). Si encore: Paramètres → Apps → Avancé → Aliases → DÉSACTIVER "python.exe" / "python3.exe". Ou utilisez bouton Tester → "Forcer local".

Appliquer $env:CARGO_TARGET_DIR = "$env:TEMP\cargo-engine-rust-2026". Permanent: Variables d'environnement Utilisateur → CARGO_TARGET_DIR.

Chrome → Paramètres → Confidentialité → Micro → Autoriser localhost. Sur IP LAN: HTTPS ou drapeau #unsafely-treat-insecure-origin-as-secure.

Normal: règlement min 8 caractères. Écrivez ex: « Skill refusé, logique invalide ».

# Brain
docker run -d --name antaerus-brain --restart always \
  --network antaerus-net \
  -v /opt/antaerus/brain/data:/app/antaerus/providers/brain_python/memory_data \
  -v /opt/antaerus/.env:/app/antaerus/.env:ro -p 8000:8000 \
  your-registry/antaerus-brain:latest uvicorn antaerus_brain.api.main:app --host 0.0.0.0 --port 8000

# Gateway
docker run -d --name antaerus-gateway --restart always \
  --network antaerus-net \
  -v /opt/antaerus/.env:/app/antaerus/.env:ro -p 8080:8080 \
  your-registry/antaerus-gateway:latest

# UI web Nginx HTTPS (LetsEncrypt certbot)
docker run -d --name antaerus-web --restart always \
  --network antaerus-net \
  -v /opt/antaerus/web/dist:/usr/share/nginx/html:ro \
  -v /opt/antaerus/web/nginx.conf:/etc/nginx/nginx.conf:ro \
  -p 80:80 -p 443:443 nginx:1.27-alpine
PS cd aNtaerus
git pull origin main
cd antaerus\interfaces\web ; npm install
cd ..\..\providers\brain_python ; py -3.11 -m pip install -r requirements.txt --upgrade
# Relancer dev-all.ps1. Migrations SQL SQLite auto au start brain.

Architecture 4 couches — flux de données

L3 Interfaces
React Web UI (port 5173) — REST /api/v1/* · WebSocket /ws
↓ JSON REST · JWT auth · Rate limit
L3 Proxy
Go Gateway (port 8080) — REST /api/v1/* | Brain client HTTP | Engine gRPC
↓ HTTP interne · headers Brain API secret
L2 Providers
Python Brain FastAPI (port 8000) — LLM · Memory SQLite · Missions · Skills registry · Proactif
↓ gRPC / appel direct Rust
L0 Kernel · L1 Providers
Rust Engine (ports 7000 HTTP · 7001 gRPC) — WASM sandbox wasmtime · STT/TTS voix · Crypto AES-256-GCM

Exemple flux complet — M7 Install skill et run sandbox

  1. Clique « Installer » Marketplace React → POST /api/v1/skills
  2. Go Gateway proxy → Brain Python POST /skills
  3. LifecycleManager : décompactage tarball, vérif ../ escape → SQLite table skills installed
  4. Clique Run Tester → POST /api/v1/skills/:id/run → Brain → Engine Rust sandbox docker/local/WASM
  5. Réponse JSON Gateway → React : badges exitCode / durationMs / fuel / sandboxKind.
