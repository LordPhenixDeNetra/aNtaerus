**Fetchers async à ajouter (tous utilisent `apiURL()` helper existant, gestion d'erreur via `throw Error(JSON.stringify({detail, message}))`):**
- `listCollectors(): Promise<ListCollectorsResponse>` → GET `/api/v1/proactive/collectors`
- `runCollector(name: string): Promise<RunCollectorResponse>` → POST `/api/v1/proactive/collectors/{name}/run`
- `runAllCollectors(): Promise<RunAllCollectorsResponse>` → POST `/api/v1/proactive/collectors/run-all`
- `listInitiatives(params?: {status?, sessionId?, limit?, offset?}): Promise<ListInitiativesResponse>` → GET `/api/v1/proactive/initiatives`
- `createInitiative(request: CreateInitiativeRequest): Promise<Initiative>` → POST `/api/v1/proactive/initiatives`
- `getInitiative(id: string): Promise<Initiative>` → GET `/api/v1/proactive/initiatives/{id}`
- `patchInitiative(id: string, request: PatchInitiativeRequest): Promise<Initiative>` → PATCH `/api/v1/proactive/initiatives/{id}`
- `runInitiative(id: string): Promise<Initiative>` → POST `/api/v1/proactive/initiatives/{id}/run`
- `getCuratorReport(): Promise<CuratorReport>` → GET `/api/v1/proactive/curator/report`
- `listPatches(params?: {reportId?, status?, limit?}): Promise<ListPatchesResponse>` → GET `/api/v1/proactive/curator/patches`
- `approvePatch(patchId: string, by?: string): Promise<CuratorPatch>` → POST `/api/v1/proactive/curator/patches/{patchId}/approve`
- `rejectPatch(patchId: string, by?: string): Promise<CuratorPatch>` → POST `/api/v1/proactive/curator/patches/{patchId}/reject`
